## Sobre este repositorio

Es el código del portafolio: un sitio estático sin build, en HTML, Tailwind CSS y
JavaScript. Incluye la hoja de vida (`cv.html`) en una versión pensada para exportar a PDF
e imprimirse, con texto real que los sistemas de seguimiento de candidatos pueden leer.

```
index.html   El portafolio

```
